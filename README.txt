SteamOS Steam+X 한글 입력: 원래 입력 경로 수정 묶음
2026-10-28 / steamos-osk-native-1.0 / 비공식 로컬 수정본

어떤 작업인가
한글을 조합하는 IBus/Hangul이나 Steam 가상키보드의 코드를 개조한 것이 아니다.
Steam이 전달하는 문자를 앱까지 운반하는 KWin 및 XWayland의 버그를 수정했다.
원래 Steam OSK → X11/XTEST → XWayland/용도별 EIS → KWin → Wayland 앱
경로를 유지한다. 터치 이벤트를 마우스로 바꾸거나 앱 입력칸에 문자를 직접 넣는
상주 우회 프로그램은 설치하지 않는다.

1) KWin: Chromium이 인식하는 Unicode 임시 키코드 사용 및 표준 Tab 변환.
2) XWayland: 임시 문자 매핑이 덮이는 경쟁 상태 수정, 대기 이벤트 문자값 보존.
3) 선택적 KWin 창 규칙: Steam OSK의 포커스와 메뉴 위 레이어 처리.

적용 범위
동봉 바이너리는 x86_64 SteamOS 3.9.5, BUILD_ID=20261023.100 및
tested-environment.json의 라이브러리 버전과 일치하는 환경에 한정된다.
원본 kwin 6.7.3-1.7 → 6.7.3-1.7.2
원본 xorg-xwayland 24.1.14-1.1 → 24.1.14-1.1.1
둘 중 하나가 이미 동봉 수정 버전이어도 나머지를 설치할 수 있다.
다른 버전에는 강제 설치하지 않는다. PORTING.txt의 소스 이식 절차를 따른다.

실기 검증은 Lenovo Legion Go S의 KDE Wayland 데스크톱에서 수행했다.
검사 통과는 바이너리 환경 일치라는 뜻이며 다른 기기의 입력 검증을 대신하지 않는다.
게임 모드, 강제 X11 브라우저, 다른 배포판의 해결까지 보장하는 묶음은 아니다.
한글 조합 엔진 및 Steam 한국어 키보드가 이미 구성된 시스템을 전제로 한다.
처음부터 한글 입력 환경을 설정하는 설치기는 아니다.

다른 기기에 적용하는 순서
압축을 풀고 이 파일이 있는 디렉터리에서 다음 명령을 실행한다.

  sha256sum -c SHA256SUMS
  python3 manage.py check

check는 읽기만 한다. OS, 아키텍처, 런타임 라이브러리, 현재 패키지 버전,
동봉 원본/수정 패키지 체크섬과 메타데이터, 대상 설치 파일 해시를 검사한다.
버전 불일치가 나오면 해당 환경용 재빌드가 필요하다. 체크를 제거하지 않는다.
현재 수정이 적용된 원래 기기는 check만 하면 된다. 재설치할 필요가 없다.

호환되는 다른 기기에 실제 적용:

  sudo python3 manage.py install
  python3 window-rule.py install

관리자 권한은 패키지 설치에만 사용한다. 창 규칙은 데스크톱 사용자로 실행한다.
창 규칙은 다른 KWin 규칙을 유지하며 자신의 항목만 백업/수정한다.
Steam 표시 언어에 따라 창 제목이 다르면 실제 가상키보드의 제목을 지정한다.

  python3 window-rule.py install --title "실제 가상키보드 창 제목"

기본 제목은 "Steam Input 가상 키보드"이며 모든 Steam 창을 대상으로 하지 않는다.
창 규칙 상태 확인: python3 window-rule.py status

설치 후 작업을 저장하고 직접 재시작한다. 설치기는 재부팅, 로그아웃, SDDM 재시작,
게임 모드 전환을 실행하지 않는다. 기본 로그인 모드가 게임이면 재부팅 후 사용자가
데스크톱 모드로 돌아와야 한다. 새 패키지는 세션 재시작 후 실제로 로드된다.
긴 문장, 중간 삽입/삭제, Tab 이동, 주소창, GTK/Qt 앱, 시작 메뉴 겹침을 시험한다.

설치·복원 동작
원본과 수정 패키지, 설치 전 버전, KWin capability를 /var/lib/steamos-osk-native에
보관한다. pacman으로 두 패키지를 한 트랜잭션에 설치하고 버전/파일을 검증한다.
실패하면 설치 직전 패키지 조합으로 복원을 시도한다. readonly는 원래 상태로 돌린다.
패키지 서명 정책을 낮추거나 패키지 업데이트를 차단하는 설정은 하지 않는다.
복원 자체가 실패하면 오류와 백업 경로를 출력한다. 전원 차단 같은 강제 중단은
자동 복원을 보장하지 못하므로 저널과 원본 패키지를 보존한다.

이 배포용 설치기로 설치한 기기의 복원:

  python3 window-rule.py remove
  sudo python3 manage.py rollback

배포 폴더를 지운 경우에도 저장된 복원 도구를 사용할 수 있다.
  sudo python3 /var/lib/steamos-osk-native/manage.py rollback

복원 후에도 저장한 다음 직접 재시작한다. 백업은 자동 삭제하지 않는다.
이 묶음 이전에 수동 설치한 원래 기기는 기존 진단 작업의 복원 도구를 사용한다.
새 설치기가 과거 설치의 백업을 임의로 만들거나 인수하지 않는다.
기존 백업이 있으면 재설치를 막아 설치 전 상태를 덮어쓰지 않는다.
OS 업데이트로 환경이 달라졌다면 과거 바이너리로 복원하는 것도 차단한다.
이 경우 현재 OS에 맞는 공식 패키지/소스로 복구해야 한다.
창 규칙 백업은 ${XDG_STATE_HOME:-~/.local/state}/steamos-osk-native/window-rule.json.
설치 후 해당 규칙을 사용자가 바꿨다면 remove는 덮어쓰지 않고 중단한다.

남는 제한
- 강제 X11 Edge 경로의 Unicode 실패는 미해결이다. 현재 Wayland 경로가 검증 범위다.
- 검증 당시 Edge 156.0.4314.50은 en-US+ko 복수 맞춤법 사전에서 별도 정지가 있었다.
  실기 검증은 한국어 사전만 켠 상태였다. 이 묶음은 브라우저 사전을 자동 변경하지 않는다.
- 주소창 첫 음절 교체로 검색어가 잠깐 비면 제안 팝업이 짧게 숨는 현상은 남을 수 있다.
- SteamOS 업데이트는 로컬 패키지를 교체할 수 있다. 업데이트 후 다시 점검하고,
  새 버전에 수정이 포함되었는지 확인한 뒤 필요한 패치만 다시 이식한다.

포함 내용
packages/: 원본 2개 + 수정 2개. SHA256은 manifest.json에 기록.
sources/: 원본 전체 소스, Valve 패치, 추가 수정, 빌드 레시피, 소스 해시.
prepare-sources.py: 새 폴더에 소스를 준비하고 설치본의 소스와 대조. 설치하지 않음.
evidence/: 개인 화면/프로필/SSH 키를 제외한 검증 요약.
test_bundle.py: 설치기 실패 복원과 창 규칙 보존 검증(시스템 명령은 모의 실행).

패키지 자체는 원래 기기에서 설치·실기 검증했다. 이 배포용 설치기의 실제 재설치는
하지 않았으며 모의 시험과 원래 기기의 읽기 전용 호환성 검사까지 수행했다.
현재 작동 중인 기기를 배포 도구 시험 목적으로 다시 설치하지 않았다.
