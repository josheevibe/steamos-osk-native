한글 전달

Chromium이 한글 키를 버리는 문제와 빠른 입력에서 임시 문자 매핑이 덮이는 문제를 수정했습니다.

Tab 이동

가상키보드의 Tab을 표준 키로 전달해 GTK·Qt 입력칸 사이를 이동하도록 했습니다.

키보드 레이어

별도 창 규칙으로 입력칸의 포커스를 유지하고 시작 메뉴 위에 키보드가 표시되도록 했습니다.

다운로드 후 먼저 검사하세요

Releases에서 아래 압축파일과 SHA256 파일을 함께 받습니다. GitHub의 자동 생성 Source code에는 설치용 패키지가 들어 있지 않습니다.

sha256sum -c steamos-osk-native-1.0.tar.gz.sha256
tar -xzf steamos-osk-native-1.0.tar.gz
cd steamos-osk-native-1.0
sha256sum -c SHA256SUMS
python3 manage.py check

검사는 시스템을 바꾸지 않습니다. 호환성을 통과한 기기에 적용할 때만 다음 명령을 실행합니다.

sudo python3 manage.py install
python3 window-rule.py install

작업을 저장하고 직접 재시작한 뒤 데스크톱 모드에서 시험하세요. 설치기는 자동 재부팅이나 게임 모드 전환을 하지 않습니다. 이미 수정이 적용된 원래 기기는 재설치할 필요가 없습니다.

남아 있는 제한

  • 강제 X11 Edge 경로의 Unicode 입력 실패는 미해결입니다.
  • Edge 복수 맞춤법 사전 문제 때문에 실기 검증은 한국어 사전만 활성화한 상태에서 했습니다. 설치기가 사전 설정을 바꾸지는 않습니다.
  • 주소창 첫 음절 교체 시 검색어가 잠깐 비면서 제안 팝업이 짧게 숨을 수 있습니다.
  • SteamOS 업데이트 후에는 수정 포함 여부와 호환성을 다시 확인해야 합니다.

복원과 다른 환경으로의 이식

이 배포용 설치기로 설치한 기기는 다음 명령으로 이전 패키지와 창 규칙을 복원합니다.

python3 window-rule.py remove
sudo python3 manage.py rollback

복원 후에도 직접 재시작합니다. OS 버전이 바뀌면 과거 패키지로의 복원은 차단됩니다. 다른 OS·라이브러리 조합은 소스 이식 안내에 따라 재빌드하고 검증해야 합니다.
